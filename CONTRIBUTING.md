## Commit Messages

Use one of these prefixes in each commit, depending on the type of change:

- `✨feat: ...` for new features, new artifacts, or new capabilities for the project.
- `🐛fix: ...` for bug fixes or corrections.
- `⚙️ci: ...` for changes to CI/CD, automation, deployment, or infrastructure workflows.
- `📄docs: ...` for changes that only affect documentation.

Keep commits focused and atomic. Commit messages must be in English only. Do
not add AI assistant co-authorship notes or `Co-authored-by` lines; all work
must be associated with the configured GitHub account.
